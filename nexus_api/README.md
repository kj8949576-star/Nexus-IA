# NEXUS API

API própria da NEXUS IA.

Responsável pela comunicação entre o NEXUS CORE, o NEXUS ENGINE e os demais módulos do sistema.

## Objetivos

- Receber solicitações.
- Processar mensagens.
- Retornar respostas.
- Conectar os módulos da NEXUS IA.
- Gerenciar a comunicação interna.
